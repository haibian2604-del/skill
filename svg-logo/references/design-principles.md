# 设计原则展开

SKILL.md 里每条规则背后的"为什么"，以及改丑了往哪个方向改。
构图范式的枚举在 `pattern-catalog.md`，本文件只讲横切的规则。

## 1. 极致简洁与留白

Logo 在真实世界里的尺寸分布是长尾的：绝大多数曝光发生在 16–48px
（浏览器标签页、列表头像、README 缩略图）。插画式细节在这个尺寸下是噪声。

- 每个 logo 最多 1–2 个核心元素。"15 个六边形的网格"是反例，
  "一个粗圆环"或"两个融合节点"是正例。
- 留白 ≥ 40% 画布。留白是设计的一部分，不是浪费；元素挤在一起必然在小尺寸粘连。
- 负空间切口必须是圆或圆角矩形，尖角切口在小尺寸下变成噪点，也让形态显得廉价。

## 2. 精确比例（viewBox 0 0 100 100）

构图围绕 (50,50)，内容不进边缘 10–15 单位（安全区，防圆角容器裁切）。

| 量 | 取值 | 越界的后果 |
|---|---|---|
| 线宽 | 2.5–4（主 3–4，次要 2） | <2.5 且线条少 → 脆弱；6 → 笨重 |
| 点半径 | 2–8 | >8 就不是"点"了 |
| 元素间距 | ≥ 8–12 | 不足 → 小尺寸粘连 |
| 透明度层次 | 背景层 0.1–0.4 / 次要 0.6–0.8 / 主体 1.0 | 层次全 1.0 → 无焦点 |

透明度 caveat：只用于**大面积背景层**。前景的小元素（节点、点）一律实心——
半透明小元素被读成"灰色脏点"，且在 16px 下直接消失；前景层级用尺寸区分。

**结构稳定**：细线 + 少量线条（如 3 条 2px 线）在视觉上撑不住——要么加粗，
要么用实心形状，要么把线系加密到 6–8 条以上。

## 3. 张力与焦点

- **不对称张力**：完全对称 + 完美居中 = 无聊且"AI 生成感"。刻意引入不平衡：
  点群左下重右上轻、主元素偏离几何中心 1–2 单位。
- **单一焦点**：视觉第一眼必须知道看哪里。多个等视觉重量的元素互相竞争是硬伤。
- **光学居中 ≠ 数学居中**：三角形绝对居中看着偏左；圆在方形容器里要略放大约 2%。

## 4. 配色（用预设路线，别现场即兴）

配色路线、hex 值与应用规则统一在 `color-palettes.md`（10 场景 × 2 路线）。
本节只讲偏离预设时的派生规则：

1. 项目已有品牌色 → 以品牌色为签名色：主色 = 同色相明度 -25%；次色 = 明度 +40%；
   强调色从色轮对面取低饱和一档；深底 = 签名色色相、明度 ≤ 12% 的近黑。
2. 深浅两底都要验：签名色在 `#111` 级深底上发暗时，明度提一档（如 #4F46E5 → #6366F1）。
3. 对比自查：签名色与浅底、签名色与深底的明度差都要 ≥ 3:1（favicon 必须过 4.5:1）。
4. 2–3 色封顶：签名 + 主/深 + 至多 1 个强调（面积 < 10%）。
5. 避开默认 Tailwind 蓝紫渐变（#3B82F6→#8B5CF6）——它是"没有做过配色决定"的标志。
   装饰克制：不加阴影滤镜（导出管线会丢），渐变至多一层且要有主题理由。

## 5. 小尺寸规则（16–32px）

- 线宽：100 viewBox 下 ≥ 2.5；favicon 单独做减法，不拿主版本缩放。
- 元素间距：≥ 线宽的 1.5 倍，否则粘成一团。
- 文字：16px 下任何小字都不可读。字母融合只保留字母的结构轮廓。
- favicon：去点缀色、去非轮廓细节，只留主形状。

## 6. SVG 工程细节

- 根元素带 `xmlns` 和 `viewBox`，不写死 `width/height`（让使用方控制尺寸）。
- 单色版把所有填充换成 `fill="currentColor"`，删掉 `<defs>` 里的颜色定义。
- 相关元素 `<g>` 分组；重复元素 `<defs>` + `<use>` 复用；交集用 `<clipPath>`。
- 需要背景圆角容器（应用图标）时，背景 `rect rx` 用画布的 ~22%（100 → rx≈22）。
- 导出 PNG 用 `scripts/render_check.py`（rsvg-convert → inkscape → qlmanage →
  无头 Chrome 自动回退），肉眼验收四档尺寸。
