# 范式库（画变体前必读）

六个范式家族 + 组合策略 + 字母融合。每个范式给构图要点和可用的 SVG 片段。
全部按 `viewBox="0 0 100 100"` 书写；片段里的 `currentColor` 是**形状骨架的占位**——
骨架画好、确认成立后，再按 `color-palettes.md` 选定的路线替换成实际 hex
（主形状 → 主色，强调点 → 强调色，负空间 → 借容器底色）。

选用逻辑：先问主题在抽象层面属于哪类（数据/网络/文本/流程/模块/融合），
再从对应家族挑范式。同一主题通常有 2–3 个家族适配——这正是 6 个变体的来源。

## 1. 点阵系统

离散的圆点/圆角矩形/胶囊构成秩序感。适合：AI、数据平台、开发者工具、模块化系统。

### 1.1 同心环点阵

2–4 环，每环点数按比例递增（如 6/12/18），点半径由内向外**递增或递减皆可**
（内环点径 ≥ 4 才能在 16px 存活），**中心留空时必须补一个实心锚点**——
空心的同心环在 16px 会被抗锯齿稀释成一圈灰点，无锚点也无焦点。

```svg
<g fill="currentColor">
  <circle cx="50" cy="26" r="2.5"/><circle cx="62" cy="29" r="2.5"/>
  <circle cx="71" cy="38" r="2.5"/><circle cx="74" cy="50" r="2.5"/>
  <!-- 外环 12 点按 30° 步进排布，此处略 -->
</g>
```

排布公式：环半径 r 上第 k 点的圆心 = (50 + r·cos θ, 50 + r·sin θ)。

### 1.2 圆角方点网格

3×3 至 5×5 网格，圆角半径取短边的 30–50%（过圆变圆点，过尖显僵硬）。
**选择性删除点位**可以拼出字母或具象形状（挖出的负空间即图形）。

```svg
<defs><rect id="p" width="12" height="12" rx="4" fill="currentColor"/></defs>
<g><use href="#p" x="20" y="20"/><use href="#p" x="44" y="20"/>
   <use href="#p" x="20" y="44"/><!-- 缺右下角一点 → 拼出形状 --></g>
```

### 1.3 胶囊点沿路径

长宽比 2:1–3:1 的胶囊，逐个旋转贴合路径切线方向，尺寸中间大边缘小，
间距略不规则营造有机感。适合工作流、协作、数据管道。

### 1.4 六边形蜂窝

完美平铺，兼具自然感与数学感。适合分布式系统、区块链、基础设施。
注意：六边形数量 ≤ 7 个，超过就违背"1–2 个核心元素"原则。

## 2. 几何形状

### 2.1 同心圆环

不同线宽的多环营造深度，可加实心中心点作强调。适合迭代、循环、完整性。

### 2.2 弧段

断开的圆制造动感，暗示运动/进度。缺口位置决定"动势方向"。

### 2.3 布尔交集

两形状重叠产生新形态，代表融合、整合。适合协作、API 网关。
SVG 里用 `<clipPath>` 取交集：

```svg
<clipPath id="a"><circle cx="42" cy="50" r="22"/></clipPath>
<circle cx="58" cy="50" r="22" fill="currentColor" clip-path="url(#a)"/>
```

### 2.4 嵌套多边形

形中有形创造深度。适合安全、稳定、分层框架。内层可用低透明度（0.3–0.4）。

## 3. 线系

### 3.1 圆形遮罩内的平行线

用平行线填充圆形边界，粗细变化制造层级。适合代码编辑器、文本/内容平台。
**遮罩出来的形状必须画出边界描边圆**——只有 clip 没有边界时，观者看到的
是几条悬空线段（正好撞通用 text/align 图标），圆根本不存在。

```svg
<circle cx="50" cy="50" r="32" fill="none" stroke="currentColor" stroke-width="3.5"/>
<clipPath id="c"><circle cx="50" cy="50" r="26"/></clipPath>
<g clip-path="url(#c)" stroke="currentColor" stroke-width="3">
  <line x1="32" y1="40" x2="68" y2="40"/>
  <line x1="27" y1="50" x2="73" y2="50"/>
  <line x1="27" y1="60" x2="73" y2="60"/>
</g>
```

注意 clip 半径（26）比边界描边圆（32）小一圈，线端与边界之间留出呼吸。

### 3.2 波形/曲线系

多条振幅不同、错位重叠的波，暗示节奏、频率、连续运动；可在关键点加点。
适合音频、信号处理、分析类产品。

### 3.3 螺旋/斐波那契

数学螺旋传达成长、演化、自然秩序。适合成长型、创意平台。

## 4. 节点网络

节点 + 曲线边。**至少 5 个节点且有一条环边**（构成"图"而非"树"）——4 节点的
分叉树会读成发芽幼苗或 git-branch 图标。层级只用**尺寸**区分（主节点 r 5–6，
次节点 r 3–4.5，全部实心）；不要用透明度区分节点，单色探索里半透明节点
被读成"灰色脏点"，且 16px 下直接消失。边用二次贝塞尔曲线（`Q`）比直线优雅。
适合 Agent 框架、图数据库、社交平台。

```svg
<g stroke="currentColor" stroke-width="2.5" fill="none">
  <path d="M48 66 Q 36 58 30 52"/>
  <path d="M48 66 Q 54 61 64 56"/>
  <path d="M30 48 Q 37 36 48 30"/>
  <path d="M64 52 Q 58 38 51 31"/>
  <path d="M64 52 Q 70 42 74 34"/>
</g>
<circle cx="48" cy="66" r="6" fill="currentColor"/>
<circle cx="30" cy="48" r="4.5" fill="currentColor"/>
<circle cx="64" cy="52" r="5" fill="currentColor"/>
<circle cx="50" cy="28" r="4" fill="currentColor"/>
<circle cx="74" cy="30" r="3.5" fill="currentColor"/>
```

**撞型警告**：单个"直杆 + 顶球"会读成图钉/书签。节点网络至少要有
2 条边、3 个节点，且节点大小有别，才能读成"网络/生长"。

## 5. 高级组合策略

1. **点阵 + 几何填充**：用点填充几何形状——形状给结构，点给质感。
   **蒙版硬裁的代价**：clipPath 裁点阵会在边缘留下月牙残点，像渲染脏点。
   只保留**完整落在边界内**的点（圆心距边界 ≥ 点半径），边缘的点缩小一号
   形成渐变过渡，不要靠蒙版切割。
2. **点阵 + 线条**：点作节点、线作连接，可加虚线作点缀；节点画在线条**之上**。
3. **几何 + 线条**：用描边而非填充定义形状，开放、技术感。经典构图：三层旋转
   叠加的正方形（0°/22.5°/45°，线宽和透明度递减）+ 中心点。
4. **分层构图**：低透明度背景图案（约 0.12）+ 高对比前景元素，创造深度。
   透明度只用于大面积背景层；前景小元素一律实心。

## 6. 字母融合

项目名首字母是好素材，但**不要渲染完整字体**——提取字母的结构 DNA，用纯几何重构：

- P = 竖线 + 半圆弧 + 底部圆点强调
- N = 左列 5 点、对角 4 点、右列 5 点（点阵字母）
- S = 两段圆弧对接

适合没有具象物的项目。判据：把字母给 5 个人看，3 秒内认得出才合格。
