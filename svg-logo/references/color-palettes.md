# 预设配色库（分场景）

配色不现场即兴——先定场景，从这里选路线。每条路线六个角色：

| 角色 | 用途 |
|---|---|
| 签名色 signature | 品牌的第一记忆点，必须出现在主 logo 上 |
| 主色 primary | 形状主体的大面积用色 |
| 次色 secondary | 层次、次要元素、渐变搭档 |
| 强调色 accent | 至多一处点缀（面积 < 10%），或 favicon 对比对 |
| 浅底 bg-light | 展示页 / 容器底色 |
| 深底 ink | 深色模式底色；也是单色回退（mono）的用色 |

冲击力分级：**restrained** 克制高级（色彩衬托图形）、**memorable** 默认档
（一个签名色建立第一眼识别）、**high-impact** 大色场强对比（货架/应用列表里跳出来）。

选法：按场景定位 → 场景内按气质选路线。项目已有品牌色时优先品牌色
（派生规则见 `design-principles.md`），没有才用预设。

## 应用规则（每条路线都遵守）

1. **主 logo**：一版签名色版 + 一版单色回退（mono 用 ink 或签名色），不把符号拆成彩色碎片。
2. **favicon / 应用图标**：用场景里**对比最强的一对**（通常是签名色 ↔ 深底），16px 下在应用列表里可认。
3. **深色模式**：深底 `ink` + 签名色/次色；签名色在深底上发暗时提升明度一档。
4. **大色场原则**：high-impact 路线签名色必须以大色块出现（背景容器/大面积形状），
   不许缩成小点缀——那就浪费了路线的冲击力设计。
5. **禁区**：彩虹配色（>3 色）、全低对比灰米调、"所有元素都重要"、装饰性光泽渐变。

需要偏离预设（品牌色、特殊审美）时：以最接近的路线为基座做替换，保持
"1 签名 + 1 深 + 1 次级 + ≤1 强调"的结构不变，并在交付说明里写明偏离原因。
