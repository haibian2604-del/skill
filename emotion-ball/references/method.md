# 会表达情绪的小球：制作方法总纲

本文件是"如何造出一颗会表达情绪的小球"的完整方法论。它描述的是一套**已被验证的实现**，
不是通用建议；照此实现可以复刻 `assets/core/` 中的核心，也可以替换任意一层。

---

## 0. 一条底层原理

> **表情的差异只由四个自由度表达：眼环形状、目光方向、身体姿态、体色。永不新增图形元素（嘴、眉毛、手、贴纸）。**

这条约束带来的效果：任何新情绪都必须用"已有的眼睛 + 姿态 + 颜色"组合出来，
于是所有表情天然同源、切换永远丝滑，且新增表情成本极低（只改数据，不改代码）。

第二条约束：**克制**。单个表情叠加的动画 ≤ 3 条；振幅宁小勿大
（目光 ±2~11，身体位移 ±1~9）；特效是事件不是常态
（彩带 / 撒花只在进入表情时触发一次；常驻的只有思考环带与睡眠 zzz）。

---

## 1. 三层架构与数据流

```
数据层  emotions（纯数据：表情配置）      ─┐
几何层  geometry（纯数据：眼环 / 身体轮廓）─┤→ 驱动层 合成 pose → 渲染层 画到 SVG
                                          ─┘
```

| 层 | 职责 | 禁止事项 |
|---|---|---|
| 几何层 | 眼环 48 点、身体轮廓环、轮廓扫描行 | 不含任何动画 / DOM 逻辑 |
| 数据层 | 表情配置（id / 名 / 池 / 参数 / 序列） | 不含 DOM、不含逻辑、不引用其他文件 |
| 驱动层 | rAF 状态机、弹簧、动画原语、表情池、兜底、SDK | 不碰 DOM 属性，只输出 pose 对象 |
| 渲染层 | SVG 骨架、球面投影、彩带、撒花、zzz | 不含业务逻辑（不知道什么是"思考中"） |

每帧的数据流：

```
now ──→ [base 姿态] ──→ [sequence 关键帧覆盖] ──→ [动画原语叠加]
      ──→ [呼吸] ──→ [弹簧步进: 形变/开合/自旋] ──→ [弹跳位移]
      ──→ [当前眼环插值] ──→ [注视平滑 + 微漂移] ──→ [主题色/开合度]
      ──→ [切换过渡 lerp] ──→ pose ──→ ball.applyPose(pose) ──→ SVG 属性
```

pose 的形状（三层之间唯一的契约）：

```js
{
  body:  { x, y, scale, rotate, color, breathe, ribbons, confetti, sketch, zzz, orbit, yaw },
  left:  { x, y, scaleX, scaleY, rotate, open, color, lookX, lookY, ring },
  right: { ...同上 }
}
```

## 2. 核心技术

### 2.1 眼环：48 点等相位轮廓 + 逐点插值

一颗眼 = 一条 48 点闭合轮廓（不是"椭圆 + 参数"，是实打实的点数组）。
形状差异（圆 / 扁 / 斜 / 闭 / 笑）全部由少量标量控制，采样公式：

```
θ_k = 2πk/48 − π/2          k = 0…47   （从正上方起，按 SVG 正方向）
r   = bot + (top − bot)·(1 + sin θ)/2   （上半高 top、下半高 bot，中线处平滑过渡）
x   = rx·cos θ · EYE_HALF · 1.16
y   = r·sin θ · EYE_HALF + tip · EYE_HALF · cos²θ
最后按 tilt 旋转并平移到左/右眼中心
```

- `top ≫ bot` + `tip>0` → **笑眼 ^**；`top ≈ bot ≈ 小` → **闭眼细线**；
  `tilt` 大且 `rx` 略窄 → **怒目**；`tip` 把两个眼角压低，是"笑眼/闭眼"成形的关键一笔。
- **硬约束：全库所有眼环必须同点数、同相位、同方向。**否则逐点插值会自交打结。
- 形变 = 两组环逐点线性插值 `lerpRing(a, b, t)`，t 由弹簧驱动（见 2.2）。
- 生成的环按 `形状|左右` 缓存（`ringCache`），一帧内不重复计算。

### 2.2 形变弹簧与"冻结起点"

用临界阻尼弹簧（ω≈6~10，ζ=1）驱动形变进度 0→1。切换眼环时**不能**从头重弹，
否则眼睛会先弹回默认形状再变形。正确做法：把当前插值结果冻结为新起点。

```js
s = clamp(spring.x, 0, 1);
src = [lerpRing(src[0], dst[0], s), lerpRing(src[1], dst[1], s)];  // 冻结
dst = newRings;  spring.x = 0; spring.v = 0;  spring.t = 1;        // 重新弹向 1
```

弹簧步进必须**分子步**（1/120s）做半隐式欧拉，否则大 dt（掉帧）时会发散：

```js
spring.v += (−2ζω·v − ω²(x − target))·dt;   spring.x += v·dt;
```

### 2.3 球面投影：让眼睛长在球上

眼睛不能直接按平面坐标摆放，否则自旋时像贴纸。做法：

1. 预先扫描身体轮廓环，每 2px 一行记录 `[minX, maxX]`（`silhouette`）。
2. 眼睛纵向位置 `ey0` 先算再钳制到轮廓内：`clamp(ey0, silMinY + halfH, silMaxY − halfH)`；
   从该行的 `[lo, hi]` 取中心 `cx0` 与半宽 `hw`。
3. 把水平偏移当作**经度**：`θ = clamp(ox / hw, −1.15, 1.15) + yaw`。
4. 余弦压缩：屏幕横坐标 `x = cx0 + hw·sin θ·0.985`，横向缩放 `×cos θ`；
   **`cos θ ≤ 0.02` 时眼睛绕到背面 → `display:none`。**
5. 纵向轻微透视收紧：`fy = √(1 − ((ey0 − HEAD_C)/130)² × 0.22)`，缩放 `sy × fy`。

副作用（也是必须的）：小尺寸实例下眼睛要放大占比 ——
≤80px 的容器给 `eyeScale: 1.5~1.8`，否则 32~48px 时眼睛不可读。

### 2.4 眨眼：弹簧 + 过冲关键帧

眨眼不是一个 `scaleY` 的 if 判断，而是**关键帧队列 → 弹簧目标**：

```
t+0    open 目标 0.05   （合上）
t+70   0.05             （停 70ms）
t+150  1.08             （睁到过冲）
t+300  1.00             （落回）
14% 概率追加第二次连眨（t+370 → 0.05，t+480 → 1）
```

开合度弹簧 ω=26，能自然吃下 1.08 的过冲；每帧：
`open = 配置基础 open × clamp(弹簧值, 0.02, 1.5)`。
`blinkMs = null` 表示不眨（睡眠 / 加载类）。
多实例不同步：眨眼相位里混入实例随机种子 `seed × 97`。

### 2.5 注视：帧率无关指数平滑 + 常驻微漂移

```
k = 1 − exp(−5.66·dt)        // 60fps 下每帧收敛约 9%，帧率无关
gaze.x += (target − gaze.x)·k
lookX += gaze.x       // 目标范围 ±24（横）/ ±15（纵），幅度克制才显含蓄
```

之上再叠加**永不完全静止**的微漂移（两相位错开的正弦），否则停住时像死图：

```
lookX += 1.4·sin(0.42w) + 0.5·sin(1.0w)      // w = now/1000
lookY += 0.9·sin(0.58w)
```

引擎**不监听 DOM**：宿主负责把指针换算成归一化坐标再调 `setGaze(nx, ny)`。

### 2.6 呼吸 / 弹跳 / 自旋

- 呼吸：`scale += br·sin(2π·now/3600)`，`y += br·55·sin(…+0.6)`。**相位用绝对时间**，
  切表情不跳变。
- 弹跳：4 段递减抛物线，高度 `48/28/14/6`，时长 `0.5/0.382/0.27/0.177s`，
  段内位移 `−4h·n(1−n)`。
- 自旋：弹簧追"整数圈"目标（ω=6.2），过程中不可打断；
  渲染层对 yaw 求导得到角速度，**|角速度| ≥ 0.9 才算"快"，≥ 5 才甩带**，
  这样收尾不会拖一堆碎带。

### 2.7 彩带：3D 轨道拖尾

彩带 = 一条在 3D 轨道上运动的头（head），后面拖着一段**历史点**形成的锥形带。

```
轨道参数化：hx = rad·sin(lam)          hy = −rad·cos(lam)·sin(tilt)
屏幕坐标：  (HEAD_C + hx·cos roll − hy·sin roll,  HEAD_C + hx·sin roll + hy·cos roll)
深度 z   ：  cos(lam)·cos(tilt)        z>0 在球前，z<0 绕到球后
```

- **前后分段**：把历史点按 `z ≥ 0` 切成连续段，前段插入前景 `<g>`、后段插入背景 `<g>`，
  每段独立成 path —— 这样彩带会真的"绕到球后面"。
- 锥形宽度 `width·(0.5 + i/(n−1)·0.5)` 头宽尾细，首尾用 `A` 圆弧封口。
- 渐变为 5-stop `hsl()`，色相随时间漂移（`hueVel` 18~42 °/s），端点跟随拖尾首尾。
- 生成时机：**自旋甩带** 角速度达阈值时按轨道平面错峰生成 3~5 条；
  **常驻环带**（思考中）低倾角、匀速、半径 124+，数量不足 2 条时每 700ms 补一条。
- 回缩用 smoothstep 收窄弧长，`ret` 到 1 才真正移除 DOM。

### 2.8 撒花：一次性物理粒子

```
初始：从球心向外随机角度、半径 96~116、速度 170~360
每帧：x += vx·dt;   vx *= 0.94^(60·dt);   vy = vy·0.94^(60·dt) + 40·dt
淡出：前 10% 淡入，其后 pow(1−u, 1.7) 淡出；旋转 + 尺寸收缩
素材：方片 / 圆点 / 18% 概率金色五角星（内径比 0.42）
上限：累计 ≤ 60 片
```

### 2.9 关键帧序列与 settle 三态

进入某些表情需要一段"表演"（睁眼、惊讶弹大、红白闪、摇头），用关键帧序列表达：

```js
sequence: { settle: 'base' | 'hold' | { next: '02' }, frames: [{ at, body?, eyes? }] }
```

- `base`：播完平滑回落基础姿态（惊讶、接收任务）
- `hold`：定格末帧（害羞变粉、生气变红、出错定格）
- `{ next }`：播完切到另一表情（唤醒 → 待机）
- 帧间用 `easeInOutCubic` 插值，帧只写差异字段（其余继承 base）。
- **缩略图一致性规则**：`hold` 且序列改变体色时，`body.color` 的基础值**必须等于序列终态色**，
  否则静态缩略图（不播序列）与实际观感不一致。

### 2.10 表情池轮换：用轮换代替硬动画

一个表情的"活气"来自**眼环形状池**：`pool: ['smile','happy']` + `poolMs: [2500, 4500]`。
到点后在池内随机跳到另一个形状，弹簧驱动形变。
`poolSpeed: 10`（半周期更快）用于检索/兴奋类，让它"看起来很忙"。

### 2.11 切换过渡

`setEmotion` 时记下旧 pose，新 pose 合成后按 `easeInOutCubic` 在 `transition` 毫秒内插值：

```
pose = lerpPose(prevPose, pose, ease(t / transition))
```

`transition` 按能量分档：兴奋类 180~400ms，低能量态 700~1200ms。
数值插值 + 颜色插值都要做（`lerpColor`）。

### 2.12 兜底：永不白屏

`handleAIMessage` 接受对象或 JSON 字符串，三条失败路径（未知 id / JSON 坏 / 缺字段）
全部 → 发 `error` 事件 + 回退 `fallbackId`（默认 `'02'`）。

## 3. 性能设计

| 手段 | 说明 |
|---|---|
| 共享 rAF 心跳 | 所有实例挂在同一 ticker Set 上，实例数不影响循环数 |
| `setActive(false)` | 视口外 / 不可见实例退订 ticker，完全停帧 |
| `renderStatic()` | 缩略图只渲染一帧：弹簧直接置终值、不播 sequence 第 0 帧 |
| `autostart:false` | 渲染静态帧但不进循环（缩略图墙默认） |
| `lite` | 关闭彩带 / 撒花 / zzz，小尺寸悬浮窗用 |
| 引用比较跳过重建 | 形变静止后直接复用目标环引用，跳过 `d` 属性重算 |
| 属性写前比较 | 颜色、fill/stroke 变化才 setAttribute |
| DOM 复用 | 彩带 / 粒子对象池化上限（8 条带 / 60 片花），超限直接丢弃 |

## 4. 参数调校速查

| 想达到的效果 | 调什么 | 建议区间 |
|---|---|---|
| 更兴奋 / 更活泼 | `transition`↓、`poolMs`↓、`poolSpeed`↑ | 180~400 / 1400~2600 / 8~10 |
| 更迟缓 / 更低能量 | `transition`↑、`openness`↓、`breathe`↓ | 700~1200 / 0.08~0.55 / 0.004~0.008 |
| 更"忙"（检索类） | `pool` 加到 4~6 个、`poolMs` 1000~1800、`poolSpeed:10` | — |
| 更"困" | `pool:['doze','closed']`、`blinkMs:null`、`openness` 0.4~0.55 | — |
| 更"炸"（惊讶） | `sequence` 首帧 0.92 → 150ms 1.45 → 420ms 1.22，`settle:'base'` | — |
| 更"凶" | `pool:['glare']` + `body.color` 红 + `jitter` 抖 + `settle:'hold'` 变红 | — |
| 更"活"（放松态） | `antics:true`（9~18s 随机自旋/弹跳/连眨） | 仅放松类开启 |
| 头微倾 | `body.rotate` ±3~10 | 别超 12，会显得歪 |

## 5. 三层边界（改错地方就会崩）

- 想加**表情** → 只改数据层（`eb-emotions.js`），零代码。
- 想加**眼环形状** → 只加一个标量对象到 `EYE_SHAPES`，或运行时 `EB.geometry.defineEyeShape()`。
- 想加**动画原语** → 只在 `ANIM_TYPES` 加纯函数 `(a, t, eng) => 值`。
- 想加**身体形状** → 只在 `SHAPES` 加轮廓环 + face 参数。
- 驱动层与渲染层是稳定基座：**不要为了一个表情去改它们**。
